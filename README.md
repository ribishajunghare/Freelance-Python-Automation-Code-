# Freelance-Python-Automation-Code-

This is my first python automation code project.

This code takes information (sales data) from a Google Sheet, adds more future dates with estimated sales target (with a 5% increase every month), filters the data for January and February 2025, and saves the final result into a file.

Steps taken to complete the task:-
 1. Connect to Google Sheets
 2. Bring the Data into Python
 3. Clean and Convert Data
    -"Day" is turned into proper date format.
    -"T GMV" (probably total sales) is made into a number format.
 4. Generate Future Sales Data
The code wants to predict or extend the data into the future, from January 1 to February 28, 2025.
5. Filter Data for Jan-Feb 2025
6. Save the Final Table to a File

End Result:
Sales target data for Jan–Feb 2025, with a 5% monthly growth, broken down by Brand and Channel.
